# Infant raw dataset QA, 2026-11-09

**Decision: BLOCKED FOR TRAINING. The earlier ready status is withdrawn.**

The audit covers all 72 raw candidate records and the 51 previously included movie-folder records. It does not certify artifact-free neuronal ground truth. Job 61013903 was cancelled; its partial checkpoint and validation metrics must not be used as scientific results or resumed.

## Checks that passed

- Six original ZIP files and README match the download-time SHA256SUMS. This establishes local integrity, not an independent publisher signature.
- Every raw candidate was decompressed, hashed and checked for finite values. Every saved calibration image equals raw frame 10.
- SciPy independently resampled raw frames using saved spatial transforms; all **1,339,648 included values** matched within numerical tolerance (maximum absolute difference 7.629394531e-06, consistent with float32 rounding). Closed-form motion calculations, full-support correlations, DVARS, inclusion masks and recoverable masks agreed for all 72 records. This verifies implementation consistency, not that the estimated transforms are anatomically correct.
- Extracted support files match ZIP member bytes/CRC and recorded SHA256. Time indices, TR conversion, coordinates, NaN masking, original family separation and all five CV family partitions passed.

## Actual defects and corrections

1. **Our acquisition counting was wrong.** Identical full raw files appear in multiple movie folders in the release. A movie-organized release is not thereby defective. Our unconditioned raw-run task treated movie-folder IDs as independent acquisitions. Seven redundant entries among the included 51 are removed, leaving **44 unique raw acquisitions: train 25, original val 4, test 15**. Family identities and original family splits are preserved. The canonical ID is lexicographically first, independent of signal quality/results; all movie aliases and raw member paths are retained. Duplicate groups were within the same family/split, so this audit found no cross-split duplication.
2. **ROI acceptance was insufficient.** All 51 included records have selected points outside the released anatomical brain support under the current spatial mapping: 28–61 of 256 points per record. This is a mismatch flag, not proof that each flagged point is nonbrain: anatomical masking errors and pose mismatch are possible. An intensity-derived registration mask is not a skull-stripped brain or cortical mask. No arbitrary test-derived exclusion threshold was applied.
3. **Calibration artifacts are not adequately screened.** Three-axis views visibly show alternating slice stripes in Aeronaut:s0607_1_4. Relative frame correlation can pass while the reference itself is corrupted. The recorded slice-alternation index is descriptive and unvalidated; it is not an exclusion rule. Centroid/reference correlations are also descriptive: the released centroid may differ in processing and pose.
4. **Robustness defects fixed:** empty reference-support morphology no longer returns the whole volume; nonfinite motion/correlation cannot supply clean targets; errors after registration cannot append two transforms or retain partial frame values; source support hashes are checked before preparation; newly generated QC NIfTI images declare mm spatial units. Historical image headers are preserved as audit evidence and corrected-unit review copies are supplied separately.
5. **Training gate added:** raw QC training requires an explicit QA approval bound to the exact manifest, every input file and unique raw-acquisition hashes, cross-checked against per-record receipts. Both old and deduplicated inventories are blocked. The old frozen launcher is also disabled by a QA marker.

## Required before release of a new training dataset

Establish the reference-to-anatomical pose, constrain ROI selection to verified brain/tissue support, and validate calibration/within-volume artifact screening. Freeze rules using development data and technical or expert anatomical review; do not choose thresholds using test prediction results. Regenerate affected raw-derived values/masks under a versioned protocol and rerun the independent reconstruction audit and family/mask checks. Any calibration strategy must preserve held-out independence or explicitly narrow the claim.

Movie decoding/gaze-conditioned conclusions remain unavailable without verified timing/gaze mapping. True corrupted-frame ground truth is unavailable; synthetic masking performance alone does not prove physiological recovery. QC uses signal values before artificial holdouts, so hidden-value independence is conditional on frozen eligibility and external spatial metadata.
